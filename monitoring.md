Azure Monitor:
Serviço que coleta e analisa métricas, logs e telemetria dos recursos. Ajuda a acompanhar desempenho, detectar falhas e tomar ações para melhorar disponibilidade.
Assistente do Azure (Azure Advisor):
Ferramenta que fornece recomendações personalizadas de boas práticas para otimizar custo, segurança, desempenho e confiabilidade dos recursos.
Ferramentas de monitoramento:
Conjunto de recursos do Microsoft Azure usados para observar e gerenciar o ambiente, como:
logs e métricas (Azure Monitor)
alertas e diagnósticos
visualização de dados (dashboards)
