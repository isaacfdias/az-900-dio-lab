No Microsoft Azure, existem várias ferramentas para implantação (deploy) e gerenciamento de recursos:

Azure Resource Manager (ARM):
Camada principal de gerenciamento. Permite criar, organizar e controlar recursos usando templates (infraestrutura como código).
Portal do Azure:
Interface gráfica via navegador, fácil de usar para criar e gerenciar recursos manualmente.
Azure CLI:
Ferramenta de linha de comando para automatizar tarefas e gerenciar recursos via scripts.
Azure PowerShell:
Similar ao CLI, mas usando comandos do PowerShell, muito usado em ambientes Windows.
Azure Cloud Shell:
Terminal direto no navegador, já com CLI e PowerShell configurados, sem precisar instalar nada.
